# Third-party notices for the shipped engine

This package ships `engine/win32-x64/rubash.exe`, a Rust build of [`rubash`](https://github.com/unixwin/rubash)
at the commit pinned in `engine.lock.json`, with this repository's patch set applied. The table below
covers every package in the build's `Cargo.lock` that the local registry cache holds.

rubash itself is MIT: its license text ships beside the artifact as `engine/LICENSE.rubash`. The crates
listed here keep their own licenses, which are all permissive; nothing in this build is copyleft, and
GNU bash (GPLv3) is never bundled — the engine implements bash behaviour itself.

Generated by `node scripts/license-scan.mjs --checkout=<rubash checkout at the pinned ref>`: 29 packages, which is every `Cargo.lock` entry present in the local registry cache — that cache holds what this build compiled. The lock's remaining 3 entries belong to other platforms or to features this build does not enable, so they are not in the binary.

## Toolchain patches

The toolchain this package ships (`toolchain/win32-x64/`) is built from the sources pinned in
`toolchain.lock.json` plus this repository's patches under `patches/toolchain/`; each component's
own licence text travels beside it in `toolchain/LICENSES/`, and `toolchain/THIRD-PARTY.md` records
which file publishes which command names.
